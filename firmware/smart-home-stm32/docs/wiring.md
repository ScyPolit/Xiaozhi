# 接线说明

## ESP8266-01S 与 STM32F103C8T6

| ESP8266-01S | STM32F103C8T6 | 说明 |
| --- | --- | --- |
| TXD | PA10 USART1_RX | ESP 发送到 STM32 接收 |
| RXD | PA9 USART1_TX | STM32 发送到 ESP 接收 |
| GND | GND | 必须共地 |
| VCC | 独立 3.3V | 不能接 5V |
| EN / CH_PD | 3.3V | 模块使能 |
| RST | 3.3V 或按钮到 GND | 低电平复位 |
| GPIO0 | 3.3V | 烧录 AT 固件时接 GND |
| GPIO2 | 3.3V | 启动保持高电平 |

ESP8266-01S 峰值电流较大，建议使用独立 3.3V 稳压模块，至少 500mA，推荐 700mA 或 1A。不建议直接使用部分 STM32 开发板自带的弱 3.3V 引脚供电，否则可能导致 ESP8266 重启、掉线、AT 无响应。

STM32F103C8T6 是 3.3V IO，可直接连接 ESP8266 串口，不需要电平转换。

## LED

| 功能 | STM32 引脚 | LED 逻辑 |
| --- | --- | --- |
| 客厅灯 | PA4 | 高电平点亮 |
| 卧室灯 | PA5 | 高电平点亮 |
| 厨房灯 | PA6 | 高电平点亮 |
| 卫生间灯 | PA7 | 高电平点亮 |
| 梳妆台灯 | PB0 | 高电平点亮 |
| 空调蜂鸣器 | PA15 | 高电平触发 |

接法一：

```text
STM32 GPIO → LED 正极
LED 负极 → 220Ω 或 330Ω 电阻 → GND
```

接法二：

```text
STM32 GPIO → 220Ω 或 330Ω 电阻 → LED 正极
LED 负极 → GND
```

## 蜂鸣器 / 空调模拟模块

PA15 用作空调模拟蜂鸣器输出，高电平有效。STM32F103C8T6 的 PA15 上电默认是 JTAG JTDI，固件会关闭 JTAG 并保留 SWD 调试功能，因此 ST-LINK 的 SWDIO/SWCLK 仍可正常烧录和调试。

提示音规则：空调打开时响 1 秒后自动拉低 PA15；空调关闭时响两下，每下 0.2 秒，中间间隔 0.4 秒。空调状态仍由接口中的 `state` 字段表示，蜂鸣器只是动作提示。

建议接线：

```text
PA15 → 有源蜂鸣器模块 IN
蜂鸣器模块 VCC → 3.3V
蜂鸣器模块 GND → GND
```

如果使用裸蜂鸣器或电流较大的模块，请使用三极管或 MOS 管驱动，不要直接让 GPIO 承担大电流。
